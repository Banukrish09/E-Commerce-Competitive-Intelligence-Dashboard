 E-Commerce Competitive Intelligence Dashboard

 -- Project Overview

The E-Commerce Competitive Intelligence Dashboard is a Data Analytics project developed to analyze e-commerce product data and identify useful patterns in product pricing, ratings, reviews, and categories.

The project uses Excel, SQL, Python, Pandas and Matplotlib,clean, analyze, visualize, and present the data in an easy-to-understand dashboard.

-- Objectives

 1.Analyze product prices across different categories
 2.Understand product ratings and customer review patterns
 3.Compare products based on price and ratings
 4.Identify high-rated and highly reviewed products
 5.Analyze product categories
 6.Create an interactive Power BI dashboard
 7.Generate useful business insights from the dataset

-- Tools & Technologies

1.Excel – Data cleaning and preparation
2.SQL – Data querying and analysis
3.Python – Data analysis
4.Pandas – Data manipulation and analysis
5.Matplotlib – Data visualization

Google Colab / Jupyter Notebook – Python development
